# Five-minute Datathon demo

## 0:00–0:40 — Problem and platform

“Wildfire decisions fail when hotspots, weather, roads and exposure arrive in separate systems. CityShield runs the complete Detect–Decide–Respond loop on LinuxONE and keeps every result traceable.” Show `/health`, platform readiness and the explicit synthetic-data badge.

## 0:40–1:40 — Detect streaming change

Click **Stream replay**. Point out each arriving observation, the increasing event count and immediate world-state update. Explain `valid_at` versus `available_at` and why this prevents hindsight leakage.

## 1:40–2:35 — Predict

Switch among 30, 60 and 120 minutes. Show P90 risk, population and the immutable forecast run ID. State that the current ensemble is an uncalibrated transparent baseline.

## 2:35–3:25 — Decide with a paired scenario

Select **dry gust** or **wind shift**. Explain that baseline and scenario use the same evidence snapshot, so the difference is attributable to the scenario. Show prioritized advisory actions and the disabled route optimizer.

## 3:25–4:10 — Respond safely

Approve the recommendation for coordination. Emphasize that approval records a human decision but sends no public warning or dispatch command. Show the new audit entry and hash.

## 4:10–5:00 — Controlled RSI and LinuxONE

Run the demo RSI evaluation. Show the shadow candidate, diagnostic metrics and promotion gates. Finish with LinuxONE deployment evidence and the next step: replace only the city package and spatial mapper.

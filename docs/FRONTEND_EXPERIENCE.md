# CityShield 前端产品与布局

## 2D / 3D 联动视图

主场景可切换 **2D map、3D scene、Both views**。两个视图读取同一批网格风险、同一个历史回放或预测时间点、同一组图层开关和选中区域；在任一视图点选网格，会同步高亮另一视图及右侧详情。2D 视图使用 SVG，即使设备没有 WebGL 也可交互。

目前 2D 和 3D 都是合成网格示意：2D 不含真实道路或居民坐标，3D 高程也未接入 Paradise 地形。界面必须保留这一来源说明。接入经过核验的城市空间数据后，才能将 2D 视图称为地理地图，并在 3D 中展示对应的真实地形与道路。历史观测、模型预测和模拟资源仍需分层标记。

## 核心原则

面向值班决策人员，一屏只回答三个连续问题：**哪里正在变危险？如果条件变化会怎样？现在需要审核什么行动？** 默认只展示完成当前问题所需的信息，详细来源、模型版本、审计和 RSI 放进可展开的“Evidence & system details”。

视觉材质借鉴 MIT 许可的 [Solid Glass](https://github.com/deeplethe/solid-glass) 设计原则：面板主体保持克制和可读，玻璃感集中在顶部高光、内侧细线、边缘描边、背景模糊和底部阴影。CityShield 使用自己的深林绿、沙金预警与火焰橙配色，并保留不支持背景模糊时的实色降级。

当前主题采用方案 B：深林绿 `#1F4433` 负责结构与背景，火焰橙 `#B05A24` 只用于活跃火情、高风险和主操作，浅薄荷 `#E4EEE6` 负责文字与高可读表面；新增沙金色 `#D7A84B` 专门表达中等级风险、预警与预测状态。

## 可操作功能

| 用户任务 | 主界面操作 | 系统反馈 |
| --- | --- | --- |
| 看懂当前态势 | 点击 **Run live demonstration**；切换 2D、3D 或并排视图，点选网格；切换 +30/+60/+120 分钟或播放时间轴 | 流入的观测逐条更新状态；两个视图同步展示风险、选中区域、历史观测与资源标记，右侧显示风险覆盖面积和暴露人口 |
| 试一个变化 | 进入 **Test a scenario**，点击风向转变、干燥阵风或增加扑救支持 | 在同一证据快照上生成配对推演；2D 和 3D 同步切换到情景结果，并自动选中变化最大的网格 |
| 做人工判断 | 进入 **Review action**，查看按优先级排序的建议并批准或拒绝 | 记录审核人和状态，形成审计记录；批准仅代表协调建议，不自动发布警报或调度 |
| 查证据与改进 | 展开 **Evidence & system details**，检查来源、审计链、模型版本；运行 RSI 演示评估 | 显示证据与预测 ID、审计哈希和影子候选模型；影子候选不会自动替换当前模型 |

## 桌面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ CityShield / 演示模式                                  [开始实时演示]        │
│ 一句话说明当前事件状态                                                      │
├───────────────────────┬───────────────────────┬──────────────────────────────┤
│ ① 看风险              │ ② 试情景              │ ③ 审行动                     │
├───────────────────────┴───────────────────────┴──────────────────────────────┤
│ 可切换的 2D / 3D 视图（约 2/3）            │ 当前步骤的信息面板（约 1/3）   │
│ 2D / 3D / 并排，点选区域同步               │ 只展示与当前步骤有关的指标     │
│ 30 → 60 → 120 分钟时间轴                   │ 情景卡片或人工审核队列         │
│ 四级风险图例 + 数据/模型限制说明           │ [下一步]                     │
├─────────────────────────────────────────────┴────────────────────────────────┤
│ 可展开：来源、证据链、模型版本、受控 RSI                                    │
└──────────────────────────────────────────────────────────────────────────────┘
```

窄屏改为上下布局，并排视图在窄屏纵向排列。默认显示 2D；无 WebGL 时仍可点选 SVG 网格和文字网格列表。

## 3D 示意的语义边界

- 当前版本使用合成 500 米网格和示意高程；颜色与火焰标记由模型对应时刻的网格风险驱动，支持动态播放。
- “风险覆盖面积”是达到关注阈值的网格面积之和；“平均覆盖面积变化率”是当前时刻与 +30 分钟基线的面积差除以时长，单位 km²/h 或 ha/h。这不是物理火线传播速度。
- P90 是当前透明集合模型的未校准状态代理，四级阈值只用于演示分层；不能据此画出精确火场边界、道路可通行性或法定疏散区。
- 确定城市后，才能用真实地形、燃料、建筑、道路和历史火场边界替换示意层，并计算、验证具有物理意义的火线传播速度与影响范围。

## 为什么这样聚合

主按钮只负责启动演示；阶段导航始终保持三项；情景使用写明变化条件的预设卡片；审核只在建议生成后出现。用户无需先理解数据源、概率分位、审计哈希或 RSI，就能完成一次“看—试—审”的任务；这些信息仍可在证据区随时核查。

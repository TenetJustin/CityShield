# CityShield 前端产品与布局

## 核心原则

面向值班决策人员，一屏只回答三个连续问题：**哪里正在变危险？如果条件变化会怎样？现在需要审核什么行动？** 默认只展示完成当前问题所需的信息，详细来源、模型版本、审计和 RSI 放进可展开的“Evidence & system details”。

## 可操作功能

| 用户任务 | 主界面操作 | 系统反馈 |
| --- | --- | --- |
| 看懂当前态势 | 点击 **Run live demonstration**；旋转、缩放、点选 3D 网格；切换 +30/+60/+120 分钟或播放时间轴 | 流入的观测逐条更新状态；网格按低、关注、较高、高四级着色，显示风险覆盖面积、面积变化率、暴露人口和所选网格信息 |
| 试一个变化 | 进入 **Test a scenario**，点击风向转变、干燥阵风或增加扑救支持 | 在同一证据快照上生成配对推演；3D 视图切换到情景结果，并自动选中变化最大的网格，显示该网格与基线的风险差值 |
| 做人工判断 | 进入 **Review action**，查看按优先级排序的建议并批准或拒绝 | 记录审核人和状态，形成审计记录；批准仅代表协调建议，不自动发布警报或调度 |
| 查证据与改进 | 展开 **Evidence & system details**，检查来源、审计链、模型版本；运行 RSI 演示评估 | 显示证据与预测 ID、审计哈希和影子候选模型；影子候选不会自动替换当前模型 |

## 3D 示意的语义边界

- 当前版本使用合成 500 米网格和示意高程；颜色与火焰标记由模型对应时刻的网格风险驱动，支持动态播放。
- “风险覆盖面积”是达到关注阈值的网格面积之和；“平均覆盖面积变化率”是当前时刻与 +30 分钟基线的面积差除以时长，单位 km²/h 或 ha/h。这不是物理火线传播速度。
- P90 是当前透明集合模型的未校准状态代理，四级阈值只用于演示分层；不能据此画出精确火场边界、道路可通行性或法定疏散区。
- 确定城市后，才能用真实地形、燃料、建筑、道路和历史火场边界替换示意层，并计算、验证具有物理意义的火线传播速度与影响范围。

## 为什么这样聚合

主按钮只负责启动演示；阶段导航始终保持三项；情景使用写明变化条件的预设卡片；审核只在建议生成后出现。用户无需先理解数据源、概率分位、审计哈希或 RSI，就能完成一次“看—试—审”的任务；这些信息仍可在证据区随时核查。
